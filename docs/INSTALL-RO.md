# Instalare și prima utilizare

About Page Writer v0.7.5; pași confruntați cu documentația oficială la 19 octombrie 2026. Nu reprezintă un test de compatibilitate încheiat. Citește fișierele înainte să activezi skill-ul.

## Claude

Activează execuția de cod/crearea fișierelor dacă este necesar în cont. Deschide Customize → Skills → + → Create skill → Upload a skill, alege ZIP-ul cu dosarul `about-page-writer/` și activează-l. [Documentație oficială](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

## Claude Code

Copiază dosarul întreg în `~/.claude/skills/about-page-writer/`. Într-o sesiune locală folosește `/about-page-writer`. Instalarea locală nu echivalează cu instalarea cloud/Cowork. [Documentație oficială](https://code.claude.com/docs/en/skills).

## Codex

Dezarhivează ZIP-ul. Copiază dosarul complet `about-page-writer/` în `.agents/skills/` din proiectul ales sau în `~/.agents/skills/` pentru utilizatorul tău. Păstrează referințele și șabloanele împreună. Selectează `$about-page-writer`; dacă lipsește, repornește Codex. [Documentație oficială](https://learn.chatgpt.com/docs/build-skills).

## ChatGPT

Aplicația desktop acceptă skill-uri individuale; distribuirea prin plugin sau workspace este separată. Verifică Skills și opțiunile disponibile în aplicația ta. Acest dosar nu este un plugin publicat sau un instalator ZIP universal pentru chatul web. [Documentație oficială](https://learn.chatgpt.com/docs/build-skills).

## Prima utilizare

Skill-ul pune întrebări înainte să completeze pagina. Răspunsurile tale aduc informațiile care nu se găsesc în sursele publice, precum experiența echipei și procesul comercial. Poți amâna sau refuza un răspuns; rezultatul rămâne atunci un draft parțial, cu lipsurile enumerate în „Recomandările Irinei”. Le poți completa ulterior cu persoana care editează site-ul.


Activează navigarea web și cere: „Folosește About Page Writer pentru pagina mea Despre noi. Site: [URL public]. Cititori: [publicul vizat]. Acțiune dorită: [ce să facă cititorii].” Fără navigare, oferă texte aprobate și așteaptă o verificare limitată. Verifică faptele, permisiunile și afirmațiile înainte să publici. Instalarea nu dovedește calitatea rezultatului.
